Notifications sur ce téléphone

Sur iPhone, les notifications arrivent seulement quand l'espace équipe est installé sur l'écran d'accueil :

  1. Dans Safari, touchez le bouton Partager (carré avec une flèche vers le haut).
  2. Choisissez « Sur l'écran d'accueil », puis Ajouter.
  3. Ouvrez Charika depuis l'écran d'accueil, connectez-vous, puis menu du compte → Notifications sur ce téléphone.

iPhone avec iOS 16.4 ou plus récent.
